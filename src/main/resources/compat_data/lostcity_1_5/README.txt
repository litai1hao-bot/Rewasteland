ReWasteland x the_lost_city structure compatibility
==========================================

Requirements: install the "the_lost_city" mod (and its own dependencies) alongside ReWasteland.
Drop this folder into <world>/datapacks/ (or zip it) and reload the world.

Structures: 13 shadow copies (id prefix rewasteland:lostcity_*).
Biomes: #rewasteland:is_apocalypse (wasteland + desert)
        #rewasteland:is_ocean (lighthouse-like, deep ocean)

Template pools and NBT templates are referenced from the source mod; nothing is copied.
