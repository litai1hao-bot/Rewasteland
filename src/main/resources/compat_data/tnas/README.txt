ReWasteland x tnew_apocalypse_structure_tnas structure compatibility
==========================================

Requirements: install the "tnew_apocalypse_structure_tnas" mod (and its own dependencies) alongside ReWasteland.
Drop this folder into <world>/datapacks/ (or zip it) and reload the world.

Structures: 24 shadow copies (id prefix rewasteland:tnas_*).
Biomes: #rewasteland:is_apocalypse (wasteland + desert)


Template pools and NBT templates are referenced from the source mod; nothing is copied.
